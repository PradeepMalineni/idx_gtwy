🚀 APIGEE PROXY GENERATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Generated Bundle Structure:
  apiproxy/
  ├── {api-name}.xml           # Main configuration
  ├── proxies/default.xml      # Proxy endpoint
  ├── targets/default.xml      # Target endpoint
  └── policies/
      ├── Spike-Arrest.xml     # Rate limiting (100/min)
      ├── Verify-API-Key.xml   # API key auth
      ├── CORS.xml             # CORS headers
      └── Response-Cache.xml   # 5-min cache

Deployment:
  • Via apigeecli (automated)
  • To 'dev' environment
  • Test URL: https://{org}-dev.apigee.net{basePath}

🔄 WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Developer: select_gateway("/path/to/api")
   → Gateway selected (Apigee or DataPower)

2. Developer: generate_and_deploy_proxy(session_id, confirmed=False)
   → Returns confirmation request with next steps

3. User confirms deployment

4. Developer: generate_and_deploy_proxy(session_id, confirmed=True)
   → Generates bundle
   → Deploys to dev
   → Returns test URL

5. Developer tests API in dev environment

Total Time: 2-3 minutes ⚡

📝 USAGE EXAMPLE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
from server import GatewayGovernanceAgent
from modules.deployment import DeploymentManager

# Select gateway
agent = GatewayGovernanceAgent()
result = await agent.process_request("/path/to/api")

# Request deployment
deployment_mgr = DeploymentManager()
deploy_result = await deployment_mgr.generate_and_deploy(
    gateway=context['gateway'],
    oas_spec=context['oas_spec'],
    oas_file=context['oas_file'],
    project_dir=context['project_dir'],
    api_name="My API",
    confirmed=True
)

print(deploy_result['test_url'])
# → https://org-dev.apigee.net/v1/myapi
